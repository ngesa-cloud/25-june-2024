The OpenSource Corruption Wiki Contribution Guide

This platform is entirely public, open-source, and decentralized. Anyone—investigative journalists, citizens, whistleblowers, or researchers—can submit verifiable evidence to expose corrupt politicians across Nairobi County and Kenya via GitHub Pull Requests.

🛡 Whistleblower Protection & Total Anonymity

You do not need to use your real identity. To contribute safely:
• Create a free burner GitHub account using a disposable or encrypted email service (such as ProtonMail, Tuta, or SimpleLogin).
• You can submit edits and Pull Requests entirely through GitHub's web interface behind a VPN or Tor Browser.
• We do not log IP addresses or request contributor identities. Only the objective validity of your evidence matters.

STEP 1

Create a GitHub Account

Sign up at GitHub.com using any username or burner email. No special permissions or software installations are needed—everything works right in your web browser.

Tip: You can use an alias handle like @kenya-watchdog-01 to maintain operational security.
STEP 2

Navigate to the Data Repository

All politician dossiers, scandals, and Evidence Locker records are stored as transparent JSON files in our public repository folder:

Directory: https://github.com/ngesa-cloud/25-june-2024/tree/main/public/api/politicians/
STEP 3

Edit an Existing Dossier or Create a New Politician

• To update an existing politician: Open their JSON file (e.g., johnson-sakaja.json) and click the pencil icon (✎ Edit this file) on GitHub.
• To add a new politician or MCA: Click "Add file" → "Create new file", name it [politician-slug].json, and paste the template below.
• If adding a new politician, also add their slug into index.json.

Example Slugs: william-ruto, johnson-sakaja, edwin-sifuna, robert-alai
STEP 4

Submit a Pull Request with Verifiable Evidence

At the bottom of the GitHub editor, describe your changes in the commit summary (e.g., "Add Nairobi County health facility audit evidence"), select "Create a new branch for this commit and start a pull request", and click "Propose changes".

Our automated validation checks verify the JSON syntax and our editorial team reviews the attached primary source proof. Once merged, the live wiki updates automatically within 60 seconds!

Evidentiary Standards: What Gets Approved

  • ✓
    Court Documents & Injunctions: High Court, Court of Appeal, or Supreme Court rulings and orders (e.g., Kenya Law Reports).
  • ✓
    Statutory Oversight Reports: Auditor General reports, Controller of Budget reviews (CBIRR), Public Procurement Regulatory Authority (PPRA) rulings, or EACC statements.
  • ✓
    Legislative Hansard: Official debate records, committee reports, and impeachment proceedings from the National Assembly, Senate, or County Assemblies.
  • ✓
    Investigative Journalism: Corroborated investigations from established media houses with documented paper trails.
  • ✗
    Strictly Prohibited: Unverified social media rumors, partisan blogs without documentation, personal family attacks, or fabricated allegations. Submissions lacking primary proof are rejected.
